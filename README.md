# 오늘날씨 AI

오늘 날씨에 맞는 가장 좋은 하루.

정적 HTML 한 파일로 작동하는 날씨 및 생활 추천 서비스입니다.

## GitHub Pages 배포
1. GitHub 계정 `hwan2277`에서 **New repository** 선택, 이름 `today-weather-ai`, **Public**, 생성.
2. 저장소의 **Add file > Upload files**에서 `index.html`, `.nojekyll`, `README.md`를 업로드하고 **Commit changes**.
3. **Settings > Pages > Build and deployment**에서 `Deploy from a branch`, `main`, `/(root)`를 선택해 저장.
4. GitHub Actions/Pages에서 완료를 확인하고 `https://hwan2277.github.io/today-weather-ai/`에 접속.

공개 저장소의 파일은 누구나 볼 수 있습니다. 외부 Open-Meteo 연결은 인터넷과 브라우저 보안 정책에 영향을 받습니다. 브라우저 위치 권한은 HTTPS 배포 후 확인하세요.
